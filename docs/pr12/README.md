# Market Weather v2.0

최신 main(PR #11 병합) 기준 `feat/market-weather-v2`.

## 변경

- `#weather`와 6개 메뉴를 유지하고 공식 Market Observation → 가상 Scenario Lab
  → 지표·모델 안내 순서로 구성한다. 다른 메뉴 구조를 개편하지 않는다.
- 실제 관측에는 방문객 통계와 비교값만 표시하며 **시장 전체 날씨: 종합 판정 유보**.
  0~100 실제 경기점수, 실측 맑음/흐림 등급, 호황/불황·예측은 만들지 않는다.
- 홈 우측은 흰색 공식 관측(방한 실적·전년비·기준월·공식 출처·갱신 상태)과
  색상이 있는 가상 시나리오 미리보기를 구분한다. Industry News 비대칭 구성 유지.
- 관측 상세는 입·출국 2개, 국적별 5개 카드. 실적/기준월/전월비/전년동월비/
  누적/전년동기비/발행기관/출처/잠정·확정 상태/정정/수집 상태를 표시한다.
- 국적별 기준월이 총 방한객 기준월과 다르면 불일치와 비교 제외를 명시한다.
  전체 기준월이 없으면 미확인이라고 표시하고 합산·비교하지 않는다.
- 최신 실적 기준월과 오늘 날짜를 구분한다. 원문 기준과 단위는 Macro와 동일.
- 상세 12개월 차트는 방한/출국 및 실적/전년비 전환. 누락은 ×, 전년 분모가 없으면
  비교 불가. 다른 월·0·보간으로 대체하지 않는다.

## 데이터·계산 경계

- `site/market-observation.js`는 fetch, 파일쓰기, 새 DB, API 키를 사용하지 않는다.
  MacroMonitor의 이미 검증된 객체와 sourceState를 render hook으로 읽는다.
- 허용 지표 ID 7개, 공식파일검증 상태·단위 명·월간·정수·최신값/시계열 일치를
  확인한다. 승인 대기 TOURGO·수입·지출·수지·소비는 allowlist 밖이다.
- 기존 Macro 원장/수집/정정/게시 승인/로드 실패 보존 정책은 변경하지 않는다.
- 시계열 차트 함수를 재사용하되 명시적 growthMode 인자를 추가해 화면 선택 상태를
  분리한다. 기존 Macro는 기본 인자로 기존 state.chart 동작을 유지한다.
- 모든 월의 전년 비교가 불가능할 때 차트가 missing count를 반환하지 않아 0개로
  보이던 부분은 실제 선택 월 개수 반환으로 보완했다. 수치·비율 계산식은 불변.
- 통계 변경/정정/지연/실패는 기존 공유 상태로 자동 반영한다. 최초 파일 실패는
  관측 불가, 이후 실패는 마지막 검증값과 실패 표시. 가상값으로 대체하지 않는다.
- PR #11 Data Observation과 브리핑은 유지. 별도 통계 시드나 공개 JSON 수정 없음.

## Scenario Lab

- 기존 점수 = clamp(0,100, round(50 + .65×방한 + .4×소비 + .25×항공)).
- 비 <45 / 흐림 45~<60 / 구름 조금 60~<75 / 맑음 ≥75, 기존 색상 유지.
- 기본 입력 21/8/6, 점수68, 초기화·슬라이더·키보드 동작 유지.
- 모든 입력은 가정값이다. 과거 '9월 보도 수치 근접' 안내도 가상 초기값으로 정정.
- 계산식은 native details로 접기·펼치기. 미검증 가중치·예측 아님을 명시.
- 공식 객체/통계 갱신이 슬라이더에 연결되지 않고 날씨 색상은 관측에 적용되지 않는다.
- weather() 함수 SHA256 main/작업본 동일: verification.json.

## 향후 실제 종합지수 설계 메모 — 미구현

1. 수요(방문객), 소비(동일 범위 지출), 공급(좌석/객실), 고용·산업활동,
   거시 환경을 구분하고 이용조건·공식 정의·관측주기·정정 정책을 검증한다.
2. 국적 5개와 총방한객은 같은 방문객 계열이다. 7개 숫자를 7개의 독립적인
   시장 측면으로 간주하거나 중복 가중하지 않는다.
3. 지표별 기준월·공표 지연·계절성·기저효과를 맞추고 공통 기간과 결측 시
   판정 유보 조건을 사전 정의한다. 미공표·승인 대기 값은 대입하지 않는다.
4. 목표 현상을 정의한 후 정규화·가중치 민감도·훈련/검증 기간·후향 개정치에
   따른 미래정보 유출을 검토하고 과거 시점 자료로 백테스트한다.
5. 성능과 불확실성·표본외 검증·운영 모니터링·방법론 검토를 통과하기 전에는
   공식 경기지수/예측/맑음 판정을 서비스하지 않는다. 인증·권리 승인이 필요한
   지표 확보는 별도 과제이며 이번 작업에서 신규 수집을 시작하지 않았다.
