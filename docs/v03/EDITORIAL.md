# PR #3 편집 기준 보완

> 아래 수치는 10월 27일 검증의 역사적 결과입니다. 10월 28일 최신 main 통계 오분류 수정·국내 공급원 재조사·최신 검증은 [국내 공급 재검토](DOMESTIC-SUPPLY-20261028.md)를 참조하세요.

이 문서와 `editorial-validation.json`이 편집 기준 보완 후의 최신 검증 결과입니다. 이전 `first-run.json`의 “total_published 12 / new_auto_published 8”은 기업공시까지 포함한 초기 보관 지표이며 Newsroom 뉴스 수를 의미하지 않습니다.

기존 혼합 `news.json`은 전체를 archive로 먼저 원자적으로 보존한 뒤 뉴스 전용 뷰로 전환합니다. 수집기의 전체 유형 중간 출력은 임시 디렉터리에만 쓰므로 공개 news.json에 SEC 공시가 잠시 섞이는 경우도 방지합니다. 다음 실행은 archive를 읽으므로 공시가 Newsroom에서 제외됐다고 저장 원장에서 사라지지 않습니다.

기간·선별 규칙에서 빠진 기존 레코드도 원장에서 삭제하지 않고 `archived_only`로 보관합니다. Newsroom 노출에서만 제외합니다. `record_type: news`와 `record_type: regulatory_filing`은 유지합니다. 전체 수집 실패 시 archive·news·newsroom·filings·briefing을 바이트 단위로 보존하고 health/지표만 갱신합니다. 손상된 archive를 조용히 뉴스 전용 파일로 대체하지 않고 오류로 중단합니다.

브라우저는 newsroom.json을 우선 읽고, 404일 때만 기존 news.json을 읽습니다. 두 경로 모두 공시와 archived_only를 다시 필터링하며 레거시 KOSIS 항목은 record_type이 없더라도 뉴스에서 제외합니다. 따라서 예전 혼합 데이터가 남아 있어도 공시가 기본 최신 뉴스로 나타나지 않습니다. 기존 브랜드·색상·CSS·메뉴 구조는 그대로 유지하고, 기존 뉴스 메타데이터 줄에 편집 구분을 표시하고 상태 줄에는 실제 최근 24시간 발행 뉴스 수를 표시합니다.

## 한국 중심 편집 우선순위

산업 관련성(Direct/Indirect/Irrelevant), 저장 권한, 편집 노출 순위는 별도입니다. 노출 순위와 근거는 각 레코드의 `editorial`에 저장합니다.

1. **korea_direct — 한국 관광산업 직접 관련**
   - 방한·한국 관광시장·서울/인천 노선 등 명시적 한국 연결, 국내 관광기업이 주체인 운영/매출 변화, 공식 지역 관광사업의 지역명+출처 근거를 사용합니다.
   - 산업 관련성이 먼저 검증돼 있어야 합니다. Indirect는 기존 승인 조건을 통과한 경우에만 명시적 한국 영향 근거로 우선순위를 부여할 수 있습니다. 산업 분류를 Direct로 바꾸지는 않습니다.
   - 한국어 기사라는 이유, 한국 매체가 썼다는 이유, 익숙한 글로벌 기업명, 기존 korea_priority 플래그만으로 승격하지 않습니다. 한국 기업이 단순 논평자/언급 대상인 제목도 주체 근거로 삼지 않습니다.
2. **global_major — 글로벌 관광산업 주요 변화**
   - 세계 산업 전체의 범위, 정량적 규모, 수요·매출·공급 등의 변화가 제목에 함께 명시된 경우에만 적용합니다. 증거 용어와 규칙을 기록합니다.
   - `Hilton Worldwide`의 회사명이나 일반 영문 항공 단어는 세계 산업 전체의 근거가 아닙니다. 이 등급도 한국 시장과의 연결은 입증되지 않았다고 별도 명시합니다.
3. **reference — 참고용 해외 산업 자료**
   - 한국 연결이나 세계 산업 전체의 주요 변화라는 근거가 없으면 자동 승격하지 않습니다.
   - 이번 GOV.UK 항공 정책·Gatwick 자료 3건은 영국 자료라는 사실만으로 한국 시장 효과를 추정하지 않고 이 등급에 두었습니다. Newsroom에서 국내 핵심 뉴스 뒤에 “참고용 해외 산업 자료”로 표시하며 일일 핵심 브리핑에는 넣지 않습니다.

정렬은 편집 등급을 우선하고 같은 등급 안에서 원래 발행일 최신순입니다. 신선한 해외 참고 기사가 오래된 국내 핵심 기사와 같은 우선순위를 받지 않습니다. 공시는 등급과 무관하게 기본 Newsroom에 포함되지 않습니다.

현재 뉴스 7건의 편집 분포는 **한국 직접 관련 4 / 글로벌 주요 변화 0 / 해외 참고 3**입니다. 세계적 중요성을 입증할 근거가 없는 자료를 억지로 중간 등급에 넣지 않았습니다. 한국 직접 관련 4건은 기존 방한객 통계와 서울·지역 관광사업으로, 새 공시나 해외 자료로 늘린 숫자가 아닙니다.

가장 구체적으로 확인된 다음 경로는 뉴스와이어의 정식 API 수신 서비스입니다. 플랫폼 목적에 맞는 제공자 승인·재사용 범위·키 발급 후 공식 스키마로 연동하고 실제 관광 분야의 당일 공급량을 측정해야 합니다. 키를 채팅이나 Git에 기록하지 않아야 하며, 이 작업에서 계정 생성·계약 수락·제공자 연락은 하지 않았습니다.
