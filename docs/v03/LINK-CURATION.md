# Newsroom: 관광산업 메타데이터 링크 큐레이션

Newsroom은 AI 기사 요약 서비스가 아닙니다. 공개 뉴스 레코드와 화면의 기사 정보는 **원문 제목, 출처, 원문 발행일, 기사 직접 링크, 관광산업 카테고리, 관련 키워드** 6개로 제한합니다. 관련 키워드는 제목에 실제 있는 산업·기업 용어를 규칙으로 추출합니다. 본문·사진·썸네일·RSS 발췌·AI 요약·재작성한 기사 표현·분석 메모는 공개 뉴스에 포함하지 않습니다.

## 이용조건 검토: 본문 재사용과 제목·링크를 구분

운영자가 2026-10-28에 **현재 무료·광고 없는 비상업 운영**임을 확인했습니다. `operating_policy.json`에 이를 기록하고 비상업 전용 소스는 설정 누락·광고·유료 접근·상업 모드 변경 시 신규 게시를 차단합니다. 수익화 전에는 기존 링크 노출과 제공자 이용조건도 재검토해야 합니다. 이 결정은 제공자의 별도 서면 계약을 받았다는 뜻이 아닙니다.

### 한국저작권위원회 자료 확인

공식 유형별 상담 검색에서 다음 항목을 직접 확인했습니다.

- [신문 기사 게시와 링크 제공 상담 항목](https://www.copyright.or.kr/business/counsel/auto-advice-service/practice/list.do?searchTarget=ALL&searchText=%EB%A7%81%ED%81%AC): ‘우리 회사가 소개된 신문 기사들을 모아 누리집에 게시하거나 링크를 제공하는 것이 저작권 침해인가요?’ (`counselSeq=3585`).
- [제목의 저작물성 관련 상담 항목](https://www.copyright.or.kr/business/counsel/auto-advice-service/practice/list.do?searchTarget=ALL&searchText=%EC%A0%9C%EB%AA%A9): 책·영화 제목·짧은 문구 등의 보호 여부를 별도 다루는 항목 (`3554` 등).
- [데이터베이스 관련 상담 항목](https://www.copyright.or.kr/business/counsel/auto-advice-service/practice/list.do?searchTarget=ALL&searchText=%EB%8D%B0%EC%9D%B4%ED%84%B0%EB%B2%A0%EC%9D%B4%EC%8A%A4): DB 일부의 추출·배포 관련 항목 (`3512`).

**확인 한계:** 검색 목록은 정상 응답했으나 연결된 상세 페이지들은 HTTP 200의 ‘작업 도중 오류’ 화면을 반환했습니다. 이를 정상 상담 답변 열람으로 계산하지 않았고, 위원회가 모든 기사 제목의 자유 이용 또는 모든 링크 DB의 적법성을 보장했다고 주장하지 않습니다. 상세 답변의 문구·예외는 미검증입니다. Google 검색은 robots 차단으로 중단했으며 우회하지 않았습니다.

검토에서는 기사 내용의 복제·요약, 원문으로 이동하는 링크, 제목의 개별 저작물성, 제공자의 계약 조건, DB의 대량·반복 추출을 각각 구분했습니다. **본문 허락이 없다는 이유만으로 모든 제목·링크도 불가능하다고 처리하지 않고**, 반대로 제목·링크라는 이유만으로 자동 접근·계약·DB 조건을 무시하지 않습니다. 이번 연결의 구체적인 이용 근거는 아래 출처의 RSS별 외부 표시 안내와 확인된 비상업 운영 범위입니다.

각 소스의 `publication.basis`와 `noncommercial_only`, 본문 권한 `not_authorized`를 별도로 기록했습니다. RSS 일반 설명을 기사 전문·사진의 재배포 허가로 확대하지 않았습니다. RSS별 표시 안내를 근거로 한 제한된 사용 판단이며 상업적 공급 계약을 확보한 것은 아닙니다.

- 공식 현재 RSS 1개씩만 요청. 전체/섹션/CDN 미러를 합쳐 공급량을 부풀리지 않음.
- 현재 피드가 제공하는 최근 **7일** 이내 메타데이터만 신규 선별. 기사 본문·목록 페이지·과거 아카이브를 크롤링하지 않고 DB 전체를 복제하지 않음. RSS 제공만으로 DB 권리가 모두 소멸했다고 판단하지 않음.
- 소스별 robots·리디렉션·크롤 지연을 요청마다 확인하는 기존 Loader 유지. 차단·403·503·robots 미확인은 실패 처리.
- 본문/RSS 설명을 분류에 사용하지 않음. 원문 링크는 제공된 기사 주소를 정규화하며 검색 결과·중간 프록시·프레임을 만들지 않음.
- 상업 전환·제공 방식 변경·이용조건 변경 시 재검토. 필요하면 해당 소스 신규 게시 중단 후 제공자 허락 확보.

### 추가 수신·게시를 보류한 경로

- **뉴스와이어:** 실제 공식 API는 존재하지만 승인·인증정보가 없음. 자체 사이트 콘텐츠 운영이 가능한 API 전용 약관과 일반 RSS/웹페이지 조건은 별도입니다. 현재 목적이 링크 큐레이션으로 바뀌었다고 상업·경쟁 서비스 제한이나 승인 절차를 무시하지 않았습니다. 비용·구체적 공개 범위는 미확인. 기존 공개 RSS는 조사 대상으로 남기고 인증 API는 미호출.
- **대한항공:** RSS 접근은 되지만 운영 정책의 허용은 개인 목적 공유이고 상업 재사용 제한도 있습니다. 공개 플랫폼 사용을 개인 목적이라고 간주하지 않아 발견 전용 유지.
- **여기어때·야놀자·하나투어·모두투어 기업 뉴스룸 후보:** 이전 조사에서 인터페이스/공개 사용 조건 미확인 또는 경로/robots/리디렉션 오류. 이번에 조건을 우회하거나 임의 승인하지 않음.
- **연합뉴스·기타 발견 전용 소스:** 제목·링크 정책으로 바뀌어도 개별 공급 조건이 확인되지 않은 경로는 게시 보류 유지.

따라서 민간기업 분야 확대는 현재 전문매체 RSS에서 **여행사·OTA·GDS·항공사·호텔 수요 관련 기사 제목**을 발견하는 경로로 구현했습니다. 각 기업의 직접 뉴스룸 계약까지 확보했다고 주장하지 않습니다.

## 데이터·호환성·자동화

- 공개 `news.json`/`newsroom.json`의 기사 객체는 정확히 `title, source, published_at, url, category, keywords`입니다. 공개 스키마 버전은 4. 기술적인 생성 시각·수집 상태는 레코드 밖에 둡니다.
- 내부 정렬·Direct/Indirect/Irrelevant 근거·ID·최초 발견 시각·권한·공시/통계 유형은 **Pages 밖 `collector_state/archive.json`**에 보존합니다. 이 디렉터리도 Git 저장 대상이므로 비밀 보관소는 아니며 본문·사진·AI 요약을 저장하지 않습니다.
- 이전 `site/data/archive.json`이 있다면 전체 원장을 먼저 외부 상태 경로에 원자적으로 보존한 후 Pages 경로에서 제거합니다. 데이터 삭제가 아니라 공개 뷰와 원장의 분리입니다. v0.2 news만 있는 경우에도 기존 레코드를 먼저 보존합니다. 손상된 원장은 뉴스 전용 뷰로 조용히 대체하지 않습니다.
- SEC `regulatory_filing`, KOSIS `statistical_release`는 내부 유형과 별도 뷰를 유지하고 Newsroom에서 제외합니다. 별도 공개 뷰도 메타데이터 6개만 내보냅니다. 예전 설명 기반 체험기사 등 게시 제외 자료도 원장에서 삭제하지 않습니다.
- 브리핑 후보도 같은 6개 필드의 링크 모음입니다. 기사 요약을 만들거나 발송하지 않습니다. 관련 키워드와 분류는 출처의 주장이나 기사 내용을 재작성하는 문장이 아닙니다.
- 제목의 방한 관광객 표기, 정량적인 한국인 호텔 숙박 의향, 명시적인 OTA/GDS 운영 변화, 관광 전담기관의 구체적인 시장 캠페인을 검증합니다. 일반 판촉·연예·직원 행사·일반 지역축제·기관 수상만으로 게시하지 않습니다. 의향·계획을 실제 실적으로 바꾸지 않습니다.
- 국내 기업·노선·한국 관광소비 등 명시적 근거로만 한국 직접 관련 순위를 부여합니다. 국내 언론사 기사라는 사실 자체는 한국 시장 영향 근거가 아닙니다.
- 기존 2시간 수집 / KST 10:30 브리핑 / 수동 실행 / Git JSON 보존 / Pages 배포 유지. 워크플로의 데이터 저장은 원장 이전 후 기존 공개 원장 파일의 제거도 커밋하도록 `git add -A -- site/data`로 보완했습니다. `operating_policy.json` 변경도 검사·배포 트리거에 포함합니다.

## 실제 검증

최종 숫자와 출처별 수치는 `link-curation-validation.json`, 공개 뉴스 예시는 `link-curation-newsroom.json`에 기록합니다. PR 검증 디렉터리의 결과이며 공개 main/Pages를 교체한 수치가 아닙니다. 최근 7일은 **원래 발행일** 기준이며 오늘 발견했다고 오늘 발행 기사로 표시하지 않습니다. 제한된 RSS는 출처 전체의 7일 발행량을 보장하지 않습니다.

출처별 수는 중복 제거 후 대표 원출처로 배분했으며 관련 출처를 중복 합산하지 않습니다. SEC 공시 6건과 KOSIS 통계 3건은 위 뉴스 표에 포함되지 않습니다. 신규 민간 기사에는 항공 노선·발권/GDS·OTA 운영정책·호텔 숙박 의향·여행플랫폼·관광시장 캠페인이 포함됩니다. 해외 OTA 기사의 한국 적용 여부는 추정하지 않았습니다.

기존 19건 원장 사본을 시작점으로 최종 분류에서 14건을 추가하고, 명시적 OTA 정책 변경 사례 1건을 추가 검증했습니다(`link-curation-integration-runs.json`). 기존 19개 ID는 모두 유지했습니다. 설명에만 관광 신호가 있던 일반 로컬 먹거리·차 체험 기사는 보관 전용으로 남겨 놓았으며 최신 뉴스 수에서 제외했습니다. Newsroom 수가 전체 보관 수와 다른 이유입니다.

- 최종 반복 수집: **신규 게시 0 / 신규 발견 0 / 중복 관측 388**. 최초 통합에서 추가된 기사를 반복 실행마다 다시 게시하지 않았습니다. 전체 반환 항목 수를 기사 확보량으로 제시하지 않습니다.
