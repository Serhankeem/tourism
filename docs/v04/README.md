# 여행기류 — Research Library v0.4

Research Library는 보고서 **메타데이터와 발행기관 공식 페이지 링크**를 제공하는 독립 라이브러리입니다. 실제 수집으로 초기 공개 자료 **110건**을 확보했습니다. PDF·보고서 본문·이미지·도표·AI 요약을 다운로드하거나 공개하지 않습니다. 9개 기관을 조사했으며 자동 발견 연결 4개, 실제 게시 자료 공급 기관은 3개입니다. 연결·검증·게시 수를 혼용하지 않습니다.

이번 결과는 `feat/research-library-v04`의 검증이며 main에 직접 병합하거나 운영 Pages를 교체하지 않았습니다. PR 검토 후 실제 주간 실행·배포 확인이 필요합니다.

### 이용 범위와 정확성

- 공개 레코드는 요청한 8개 필드(`title, publisher, published_at, report_type, category, keywords, url, access_type`)뿐입니다. 제목은 원문 그대로이며 분류/키워드는 제목·허용된 서지 메타데이터에 근거합니다.
- 공개 카탈로그의 사실형 서지정보 인덱싱 판단과 PDF·보고서 본문의 저작물 이용허락은 다릅니다. 공개 홈페이지가 있다는 이유만으로 모든 재사용·모든 자동 접근을 허용하지 않습니다. 각 기관의 별도 제한이 확인되면 보류합니다.
- 로봇 규칙·TLS·리디렉션·대기시간·기관별 호스트/공개 검색 양식 허용목록을 적용합니다. 외부 호스트 리디렉션, 파일 다운로드 경로, PDF/이미지 응답은 거부합니다. 실제 보고서 파일을 열어 내용을 읽거나 AI에 입력하지 않습니다.
- KCTI는 발간년도만 확인되는 경우 `2025`를 그대로 저장하고 **발간연도 2025년 · 월·일 미표기**로 표시합니다. 별도의 작성일(예: 2026-01-12)을 발행일로 바꾸거나 임의의 1월 1일을 만들지 않습니다.
- ETC·Phocuswright의 공식 구조화 최초 공개일은 **공식 공개일**로 표시합니다. 수정일·제목의 기준 분기/월을 날짜로 추정하지 않습니다. 인쇄본 발행일을 별도로 확인했다는 뜻은 아닙니다.
- 야놀자리서치의 날짜는 등록일입니다. 현재 `allow_registered_date:false`로 보류합니다. 등록일 표시를 별도로 허용하더라도 UI가 ‘공식 등록일 · 발행일 미확인’을 표시하며 최근 30일 **발행** 지표와 섞지 않습니다.
- KCTI는 원문 제목과 출처를 바꾸지 않고 공공누리 표시·저자를 추가 출처 정보로 보여 줍니다. 보고서 내용·PDF를 이용하지 않습니다.
- 접근 구분은 **무료 공개 19 / 유료 11 / 회원 접근 0 / 미확인 80**입니다. 랜딩 페이지 공개를 유료 원문 무료 이용으로 오인하지 않았습니다. 파일을 다운로드하지 않아 확인할 수 없는 접근 구분은 미확인으로 남겼습니다.

## C. 자동 수집·저장 검증

- [첫 실행](first-run.json): 후보 170, 고유 검증 113, 신규 공개 **110**.
- [실제 반복 호출](repeat-run.json): 신규 공개 **0**, 공개 **110** 유지. 같은 URL/이미 발견한 문서의 중복 관측 228개와 동일 자료 통합 1개를 구분합니다.
- 기관별 실제 목록/랜딩 HTTP 수집 성공률은 연결한 4개 기관에서 2회 관측 모두 성공입니다. 야놀자리서치의 ‘HTTP 성공’은 발행일 검증/게시 성공이 아닙니다. 미연결 5개 기관의 성공률은 0%로 계산하지 않고 ‘미시도/미연결’로 표시합니다.
- 출처별 최신 발행 정보: KCTI **2025년(월일 미표기)**, Phocuswright **2026-10-28**, ETC **2026-10-14**. 등록일만 있는 야놀자리서치는 최신 발행일을 만들지 않았습니다.
- 자동 등록과 수동 등록의 최초 발견 경로를 구분하고, 최초 발견 시각·최종 메타데이터 확인 시각·수집 방식·권한·검증 상태·기관 문서 ID·별칭·메타데이터 응답 해시를 내부 원장에 보존합니다. 메타데이터 수정 이력도 보관하며 본문은 저장하지 않습니다.
- 전체 실패 시 기존 `reports.json`과 원장을 바이트 단위로 보존하고 오류/시도 지표만 기록합니다. 개별 랜딩 실패도 이미 검증한 자료를 삭제하지 않습니다. 손상/분실 원장을 뉴스/공개 뷰로 조용히 대체하지 않습니다. 권한 표시가 사라진 자료는 원장에 보존하고 게시 재검토 대상으로 돌립니다.

### 파일과 실행

- `site/data/reports.json`: 공개 8개 필드 목록 + 기관/날짜 정밀도/필수 출처 표시용 보조 메타데이터.
- `collector_state/reports_archive.json`: 전체 원장. Pages 밖이지만 Git 저장소가 공개될 수 있으므로 비밀/보고서 본문을 저장하지 않습니다.
- `collector_state/reports_candidates.json`: 후보·중복·검증/보류 근거.
- `reports_sources.json`: 9개 기관, 제공 경로·조건·주기·기간·조사 결과. 2차 확장은 별도 목록.
- `site/data/reports_health.json`: 기관별 연결·확보·오류·최신성 지표. 원문이 아닙니다.
- 기존 `research.json`(KOSIS), `news.json`, `newsroom.json`, `briefing.json`, `filings.json`, 뉴스 보관 원장은 변경하지 않았습니다.

```bash
python3 -m unittest discover -s tests -v
python3 -m src.reports.engine --progress
# 같은 주에도 재검증. 권한·robots 제한은 바뀌지 않습니다.
python3 -m src.reports.engine --force --progress
python3 -m src.reports.report
python3 -m http.server 8000 --directory site
```

자동 수집이 불가능하지만 메타데이터 사용이 승인된 기관은 `--import-manual /path/to/reviewed.json`을 사용합니다. 파일의 `reports` 배열에 공개 8개 필드와 `source_id, verified_by, verification_note, evidence_url`을 제출해야 합니다. 기관/링크/날짜/분류/검증 근거를 검사하고 `operator_attested`로 구분합니다. KCTI 수동 등록에는 실제 공공누리 유형과 저자도 필요합니다. 사용 조건이 미확인된 기관의 등록을 이 옵션으로 우회할 수 없습니다. 이번 초기 DB에는 수동 자료가 없습니다.

### Actions·Pages

- 기본 주간 실행: **월요일 07:40 KST** (`40 22 * * 0` UTC), `workflow_dispatch` 지원. GitHub는 예약을 지연할 수 있습니다.
- 기본 7일 주기는 한국시간 달력 주 기준으로 처리해 첫 목요일 검증 후 다음 월요일이나 스케줄 지연 때문에 한 주를 건너뛰지 않습니다. 기관별 `interval_days`를 다르게 설정할 수 있습니다. `force`는 실행 주기만 무시합니다.
- 기존 뉴스 수집의 2시간/10:30 브리핑 예약은 유지합니다. 두 워크플로의 운영 수집·배포 작업은 동일한 `tourism-pulse-publish` 잠금으로 커밋부터 전체 Pages 배포까지 직렬화합니다. 읽기 전용 PR 테스트는 이 잠금을 잡지 않습니다.
- 배포 작업은 대기 후 최신 main을 체크아웃하고, 저장 후 `git pull --rebase`로 다른 정상 커밋을 보존한 뒤 Push합니다. 충돌 시 강제 Push하지 않습니다. 실제 임시 Git 원격 테스트에서 동시 뉴스 커밋과 Research 원장이 모두 새 체크아웃에 남는 것을 확인했습니다.
- Research 저장 단계는 `reports*.json` 및 `collector_state/reports_*.json`만 추가합니다. 뉴스·KOSIS·기업공시를 쓰지 않습니다. 같은 기존 `site` 전체를 Pages artifact로 배포하므로 Research와 Newsroom이 함께 유지됩니다.
- PR에서는 테스트만 실행하고 main 전용 수집/배포는 건너뜁니다. 검토·병합 후 수동 실행으로 Git 보존과 공개 페이지를 확인하고 다음 주간 실행을 관찰해야 운영 검증을 완료할 수 있습니다.

## E. 남은 과제

1. 야놀자리서치 등록일을 별도 표시해 수록할지 확정하거나 공식 발행일 메타데이터 확보. 현재 55건을 발행일 검증 완료로 계산하지 않습니다.
2. KTO/관광데이터랩의 허용 HTTPS 발간물 경로/API, UN Tourism의 robots 접근 오류 원인과 공식 수신 경로 확인.
3. McKinsey·WTTC의 공개 전문 플랫폼용 서지정보/자동 접근 범위, IATA의 명시적 자동 수집 제한에 대한 허락 확인. 이메일 발송·계정 생성·약관 수락·계약은 대신 수행하지 않았습니다.
4. 원문 접근 구분 미확인 80건과 연도만 있는 KCTI 날짜 정밀도 개선. 유료 자료를 내려받아 해결하지 않습니다.
5. 항공·MICE 공급과 분야별 다양성 보완. 2차 후보 **OECD·ICCA·한국MICE협회**는 별도 조사 대상으로만 기록했으며 초기 110건이나 9개 기관 실적에 포함하지 않았습니다.
6. 병합 후 실제 주간 실행/Pages 반영 관측, 소스 변경·조건 재검토, 실제 업데이트 지연과 자료별 품질 점검.
