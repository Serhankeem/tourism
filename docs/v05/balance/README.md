# 관광수지 연동 준비 — 승인 대기

2026-10-30 조사. 이 PR은 웹 공개나 TOURGO 정기 다운로드를 활성화하지 않는다.
실제 수치, 원본 XLS, 기관 원문/화면, 인증키는 이 문서 및 Git에 포함하지 않는다.

## 완료된 기술 범위

- `balance.py`: 공식 XLS의 연도/월/천 US$ 단위/연간합계 검증, 빈칸 보존,
  수입·지출 비음수/수지만 음수 허용, 동일 기준월 집합 및 수입−지출=수지 대조.
- 천 US$ 원장을 보존하고 백만 US$ 변환은 정확히 1,000으로 나눈다.
- 월별 원장 병합은 복사본에서 수행하고 과거 누락 월을 삭제하지 않는다.
  값·잠정/확정 상태 변경 시 이전/이후 값과 출처 SHA256/탐지시각 보존.
- 원문이 확정 여부를 명확히 하지 않으면 `not_stated`. 오래된 잠정 안내로
  최근 자료를 확정치라 추정하지 않는다. 기준월과 수집시각도 별개다.
- 수입/지출 전월비·전년동월비, 수지 전월/전년 증감액. 적자/흑자 전환의
  퍼센트 오해를 피하려고 수지 퍼센트는 제공하지 않는다. 누락 분모는 null.
- `synthetic_test`와 `official_export` 원장 혼합 금지. 테스트는 인공값만 사용.
  1인당 지표는 분모 정의 미검증이므로 계산하지 않는다.
- `macro_sources.json`의 TOURGO 소스는 disabled. `collection`/`publication`
  승인은 각각 기본 false. boolean true, 범위, 근거참조, 유효시작/종료일이 필요.
  승인 근거는 비공개 계약 원문/개인정보 대신 내부 문서 식별자를 사용한다.
- 기존 collector도 승인 없는 소스의 수집을 건너뛰며 public_view는 원장에
  값이 있더라도 게시 승인 전에는 노출하지 않는다. enabled만 바꿔도 수집 불가.
  승인 후에도 이 PR은 TOURGO 네트워크 transport를 활성화하지 않는다.

## 실자료와 테스트의 분리

`balance_prepare`는 운영자가 이미 확보한 공식 XLS 3개만 오프라인 검증한다.
선택 의존성 `xlrd==2.0.2` 설치가 필요하다. 기존 collector/CI는 이 의존성이 불필요하다.

```
python -m src.macro.balance_prepare --receipts /private/receipts.xls \
  --expenditure /private/expenditure.xls --balance /private/balance.xls \
  --private-dir /private/macro-ledger
```

출력은 반드시 저장소 밖 경로여야 한다. 웹/collector_state 출력 경로는 거절한다.
실제 파일은 저장소 밖에서 3개 지표 각 68개월(2021-01..2026-08), 총 204개
관측값에 대해 월 집합/수지 항등식 검증을 통과했다. 공표수치와 원장은 Git/Pages에
넣지 않았다. 이 로컬 검증은 예약 수집이나 실서비스 게시 검증을 뜻하지 않는다.
기존 방문객 기준월과 이 자료의 기준월을 강제로 맞추거나 채우지 않는다.

## 공식 경로 재검토

| 경로 | 접근/조건 확인 | 결론 및 다음 작업 |
|---|---|---|
| KCTI OpenAPI `getTourismBalcList` | 앞선 무키 HTTPS 요청 503 upstream timeout. 등록주소의 `EdrcntTourismBalnaceService` 철자 유지 | HTTPS 정상 XML 응답/현재 운영 여부 미확인. 키 전송 금지 유지. 기관 확인 후 `TOURGO_SERVICE_KEY` 사용 예정 |
| TOURGO 공식 엑셀 | 정상 UI 다운로드로 68개월 검증. 약관 제15조의 사전승낙 제한 및 KOGL 미표시 자료 협의 정책 | 외부 수치 게시·자동 다운로드 허용 범위 회신 필요. API의 KOGL1을 파일에 전용하지 않음 |
| KTO 연도별 관광통계 XLSX | 공식 홈 200. 홈에 제공된 관광통계/발간보고서 목록 `cbIdx=1603`, 통계 목록 `cbIdx=1127`은 이번 요청에서 HTTP 루트로 302 | HTTP downgrade는 따르지 않음. 요청한 연도별 파일과 **그 게시물의 KOGL1 표시**, 경제지표 정의·시트·단위는 아직 미검증. 공공누리1 조건의 연간 지표 후보이며 연결 안 함 |
| ECOS 일반여행 | 공식 API 안내 `https://ecos.bok.or.kr/api/` 200. 클라이언트 렌더링 안내 셸만 확보; 인증키 미설정 | 공식 표/일반여행수입·지급 항목코드 및 단위 확정 못 함. 전체 여행수입/지급 코드로 대체하지 않음 |

KTO 연간 파일이 확보되더라도 연간 총액을 월별로 나누거나 TOURGO 월값 대신
사용하지 않는다. 연도/공표일/잠정 상태를 별도 기록할 연간 지표로만 검토한다.
월 통계 게시물의 KOGL0과 요청한 연간 파일의 KOGL1도 구분한다.

## 기관 확인 또는 사용자 작업

1. TOURGO 담당기관에 비상업 웹사이트 수치·파생 비교 게시, 1일 1회 이하 공식
   파일 자동 다운로드, 출처표시 방식, 수정/보관 허용 범위 확인. 에이전트가 연락하지 않음.
2. 허용 회신을 보관한 뒤 각 승인 범위·유효일·근거참조를 설정 변경 PR로 반영.
   설정 변경만으로 배포하지 않고 transport 및 기존 공개 원장 연결을 별도 검증해야 함.
3. KTO 연간 XLSX는 공식 게시물 URL/다운로드/KOGL 표시 확인 후 연간 어댑터 검토.
4. ECOS 활용 신청 후 GitHub Secret `ECOS_API_KEY` 등록. 키는 채팅/코드/로그에
   넣지 않음. 공식 StatisticTableList/StatisticItemList의 이름·계층·주기·단위로
   일반여행 항목을 확정하고 공식 원문 수치와 대조한 뒤 연결. 코드 추정 금지.
